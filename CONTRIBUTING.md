# Contributing to AI Travel Planner Agent

First off, thank you for considering contributing to the AI Travel Planner Agent! It's people like you that make this hackathon project such a great tool.

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue detailing the problem, steps to reproduce, and your expected outcome.

### Suggesting Enhancements
Have an idea for a new agent or feature? Create an issue with a detailed explanation of your proposed enhancement and how it aligns with the multi-agent architecture.

### Pull Requests
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Make your changes and commit them (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

Please ensure your code follows the existing style, includes appropriate tests, and updates documentation where necessary.
